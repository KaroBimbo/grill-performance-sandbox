# Гриль-перфоманс

Статический лендинг-игра для GitHub Pages.

## Как опубликовать бесплатно

1. Загрузите эти файлы в репозиторий GitHub.
2. Откройте `Settings` → `Pages`.
3. В `Build and deployment` выберите `Deploy from a branch`.
4. Укажите ветку `main` и папку `/root`.
5. Через пару минут сайт появится по ссылке GitHub Pages.

## Что внутри

- выбор ингредиентов в игровой форме;
- рецепты для аэрогриля под выбранное время;
- включаемая фоновая музыка через Web Audio;
- Lottie Web-анимации с локальными JSON-ассетами в `assets/lottie`;
- локальные иллюстрации для шефа, доски и тарелки в `assets`.

## Про музыку

Кнопка музыки включает файл `assets/music/gubnaya-garmoshka.m4a` по кругу.
Если файла нет, сайт автоматически включает встроенный уютный фон через Web Audio.
